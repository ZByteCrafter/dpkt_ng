## Part B: pop3.py

### Task 3: 修复多行响应文本重复 (Critical)

- [ ] **Step 1: 修改 line 113-114 和 152-153**

```python
# 修改前 (两处):
self.responses.append(POP3Response(self._ml_start + b' ' + raw))

# 修改后:
self.responses.append(POP3Response(raw))
```

原因: `self._ml_buffer[0]` 已包含完整状态行（如 `+OK 2 messages`），`raw` 以状态行开头。再加 `self._ml_start + b' '` 会导致 `+OK +OK 2 messages`。

- [ ] **Step 2: 添加测试验证**

```python
def test_pop3_feed_multiline_text():
    """Feed-parsed multiline response text should not duplicate status."""
    p = POP3()
    p.feed(b'+OK 2 messages\r\n1 120\r\n.\r\n')
    assert len(p.responses) == 1
    assert p.responses[0].text == b'2 messages'  # NOT b'+OK 2 messages'
```

- [ ] **Step 3: 提交** `git commit -m "fix: POP3 multiline response text duplication"`
